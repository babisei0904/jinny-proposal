# 영상 자동화 프로그램 개발 검토서

작성일: 2026-10-19
대상: 숏츠/영상 제작 자동화 프로그램 (혼자 쓰는 로컬 프로그램, 로그인 없음)
벤치마크: ShortTube(숏튜브) 웹앱 캡처 5장, 사용 영상 2개

---

## 1. 한 줄 결론

**전체적으로 만들 수 있다. 다만 "요청한 그대로"가 아니라 아래 3가지는 방식을 바꿔야 한다.**

| 항목 | 요청 | 검토 결과 | 대안 |
|---|---|---|---|
| 구글 플로우 연동 | Flow 사이트로 사진→영상 | **불가.** Flow는 웹 UI만 있고 공개 API가 없음 | 같은 모델(Veo 3.1)을 **Gemini API**로 직접 호출 (공식 지원, 9:16·이미지→영상 가능) |
| 브루(Vrew) 연동 | 자막 만들기 → 브루 | **API 없음.** 프로그램에서 직접 호출 불가 | 프로그램이 **Whisper**로 자막(SRT)을 만들고 캡컷에 바로 넣음. 브루는 "열어서 다듬기" 수동 단계로만 남김 |
| 캡컷 자동 편집 (pycapcut) | pycapcut으로 캡컷 프로젝트 생성 | **조건부 가능.** 공식 지원은 **Windows 캡컷**만. Mac 캡컷에서 열리는지 미검증 | 1차로 Mac에서 테스트. 실패하면 Windows PC에서 캡컷 열기, 또는 ffmpeg 직접 렌더링으로 대체 |

나머지(대본 생성, TTS, 자막 제거, 자르기, 썸네일, 용량 줄이기, 장면 분석 배치)는 모두 **가능**하다.

## 2. 먼저 확인해야 할 전제 (답변 필요)

1. **작업 PC가 Mac인가 Windows인가?**
   올려주신 녹화 파일 이름(`스크린샷 2026-10-16 오후 6.15.35.mov`)이 macOS 형식이라 Mac으로 보인다. 벤치마크 프로그램(ShortTube)은 Windows에서 실행된 화면이었다.
   pycapcut 제작자가 "생성된 초안은 Windows 캡컷에서 열어 수동으로 내보내라"고 명시하고 있어, **Mac이면 가장 먼저 호환 테스트를 해야 한다.** (Mac 캡컷은 샌드박스라 외부 경로 소재를 못 읽는다는 보고도 있다.)
2. **GPU가 있는가?** 중국어 자막 제거(AI 인페인팅)는 NVIDIA GPU가 있어야 실용적인 속도가 난다. Apple Silicon도 돌아가지만 느리다. 없으면 15초 영상에 수 분~수십 분 걸릴 수 있다.
3. **캡컷 버전.** pycapcut은 CapCut 8.2 / 9.5에서 검증됐다. 최신 버전에서 초안 암호화가 들어가면 깨질 수 있으므로 버전을 고정하는 편이 안전하다.
4. **유료 API 사용 의사.** 아래 비용 항목 참고. Veo 영상 생성이 가장 비싸다.

## 4. 주요 리스크와 대응

### 리스크 1. pycapcut × Mac 캡컷 (가장 큼)
- 제작자 문서: "생성된 초안은 **Windows 버전 CapCut**에서 열어 수동 내보내기." Mac 지원은 언급 없음, 이슈도 없음(미검증 상태).
- 라이브러리는 0.0.x 버전이고 0.1.0에서 API가 바뀔 예정. 버전 고정 필요 (`pycapcut==0.0.4`).
- **대응:** 개발 첫날에 "영상 2개 + 자막 1줄" 초안을 Mac 캡컷 초안 폴더(`~/Movies/CapCut/User Data/Projects/com.lveditor.draft`)에 넣어 열리는지 확인.
  - 열리면 → 그대로 진행.
  - 안 열리면 → (a) Windows PC/가상머신에서 캡컷 열기, (b) 캡컷 없이 ffmpeg/MoviePy로 최종 mp4까지 렌더링하는 "직접 렌더" 모드 추가. (b)는 캡컷에서 손보는 자유도가 없어지지만 완전 자동이 된다.

### 리스크 2. Google Flow 미연동
- Flow는 브라우저 자동화(클릭 매크로)로 흉내낼 수는 있지만 약관 위반 소지와 UI 변경 때 깨짐 문제가 커서 권하지 않는다.
- **대응:** Gemini API의 Veo 3.1 사용. 같은 모델이고 9:16, 이미지→영상, 시작·끝 프레임 지정, 레퍼런스 이미지 3장까지 공식 지원. 영상은 서버에 2일만 보관되므로 생성 즉시 다운로드하도록 구현.

### 리스크 3. 대본↔장면 자동 매칭 정확도 (3번 영상)
- 0.5~2초 컷을 수십 개 배치하는 건 "AI가 장면을 얼마나 잘 이해하느냐"에 달려 있다. 첫 결과가 70~80% 수준이고 나머지는 사용자가 캡컷에서 손보는 걸 전제로 설계해야 한다.
- **대응:** 매칭 결과를 표로 보여주고 드래그로 바꾼 뒤 초안을 생성하는 "검수 단계"를 UI에 둔다. (벤치마크의 "임시 편집 구성" 화면과 같은 개념)

### 리스크 4. 자막 제거 품질과 속도
- 흰 배경·단색 배경에서는 깨끗하고, 자막 뒤로 손이나 상품이 움직이면 뭉개진다.
- **대응:** 자막 영역 지정 모드 기본 + 결과 미리보기. 안 되는 영상은 "자막 영역을 9:16 크롭으로 잘라내기"가 더 빠른 경우도 많다(크롭 기능과 결합).

## 5. 제안 구조

벤치마크(ShortTube)와 같은 **브라우저 UI + 로컬 서버** 구조를 권한다. 설치형 앱(Electron/PyQt)보다 만들기 쉽고, 폰에서도 같은 와이파이로 접속해 진행 상황을 볼 수 있다.

```
브라우저 (localhost:4000)
  대시보드: [1 여행숏핑] [2 쇼핑숏츠] [3 일상컷편집] [4 vlog/일반]
            [자막 제거] [영상 자르기] [썸네일] [용량 줄이기]
            [대본 만들기] [목소리 넣기] [자막 만들기] [설정(API 키·프리셋)]
        │
        ▼
Python 서버 (FastAPI)  ── 작업 큐 (긴 작업은 백그라운드, 진행률 표시)
  ├─ ffmpeg            : 자르기/크롭/음성 제거/압축/프레임 추출
  ├─ pycapcut          : 캡컷 초안 생성 (트랙, 컷, SRT, 전환)
  ├─ OpenAI API        : 대본·제목·매칭 판단
  ├─ Gemini API        : Veo 3.1 영상 생성, 영상 장면 이해
  ├─ Fish Audio API    : TTS, 보이스 클론
  ├─ faster-whisper    : 자막 타임스탬프 (로컬, 무료)
  ├─ video-subtitle-remover : 중국어 자막 인페인팅 (로컬)
  └─ Pillow            : 썸네일 합성
        │
        ▼
프로젝트 폴더 (영상별)  ──►  캡컷 초안 폴더  ──►  캡컷에서 열어 확인·내보내기
```

- 프로젝트 하나 = 폴더 하나(원본, 대본, 음성, SRT, 분석 결과 JSON, 초안). 벤치마크의 "저장하기 / 내 보관함"에 해당.
- 프리셋(각색 프롬프트, 제목 프롬프트, 오프닝·아웃트로 멘트, TTS 목소리·스타일)은 JSON 파일로 저장.
- 로그인·결제 없음. API 키는 설정 화면에서 입력해 로컬 파일에 저장.

## 6. 영상 종류별 파이프라인

### 1번 여행 숏핑숏츠
1. 사진 7장 업로드 + 사진별 메모(수영장/객실/시그니처 공간)
2. GPT로 대본 생성 (프리셋 선택, 버전 2~3개 제시)
3. 사진별 Veo 프롬프트 자동 생성 (카메라 무빙 지정) → Veo 3.1 이미지→영상 (9:16, 6~8초) → 다운로드
4. Fish Audio TTS → 음성 파일
5. Whisper로 음성에서 문장별 시간 추출 → SRT
6. pycapcut: 영상 7개를 대본 길이에 맞춰 배치, 음성 트랙, 자막 트랙, 전환, (옵션) 광고 표시 텍스트
7. 캡컷에서 열어 내보내기

### 2번 쇼핑숏츠
1. 타오바오 영상 1~3개 업로드 → 구간·9:16 크롭 설정 (벤치마크 1단계와 동일)
2. 자막 제거 (영역 지정) + 음성 제거
3. Gemini 영상 이해로 각 영상의 장면 목록 추출 (시간, 내용 설명)
4. 대본: AI 생성(장면 설명 기반) 또는 직접 입력 → 문장 분할
5. GPT가 문장마다 어울리는 장면 구간 선택 → 검수 화면에서 수정
6. TTS → SRT → pycapcut 조립 → 캡컷

### 3번 일상 컷편집 / 4번 vlog
1. 영상 여러 개 업로드 (수십 개 가능)
2. 영상마다 장면 분석 (Gemini) → "클립 카탈로그" 저장 (한 번 분석하면 재사용)
3. 대본 입력/생성 → TTS → 문장별 길이 산출
4. 문장별로 카탈로그에서 장면 선택. 3번은 한 문장에 1~3컷(0.5~2초), 4번은 한 문장에 1컷(길게)
5. 검수 → pycapcut → 캡컷

## 7. 필요한 것

### 계정·API 키
| 서비스 | 용도 | 비용(공식 가격 기준, 확인 필요) |
|---|---|---|
| OpenAI | 대본·제목·매칭 | 영상 1편당 수십 원 수준 |
| Google AI Studio (Gemini API, 유료 등급) | Veo 3.1 영상 생성, 영상 장면 이해 | Veo 3.1 **초당 $0.40**(720p/1080p), Fast 초당 $0.10, Lite 초당 $0.05. 여행숏츠 1편(8초×7장)≈ 표준 $22 / Fast $5.6 / Lite $2.8. 영상 이해(Gemini 2.5 Flash)는 입력 100만 토큰당 $0.30으로 저렴 |
| Fish Audio | TTS·보이스 클론 | 종량제, 제3자 자료 기준 100만 바이트당 약 $15 (한글 1자≈3바이트 → 1편 300자≈$0.014). 공식 가격 페이지에서 재확인 필요 |
| (선택) 브루 | 자막 수동 다듬기 | 기존 요금제 |

### 소프트웨어
- Python 3.11+, ffmpeg, CapCut 데스크톱(버전 고정)
- pip: `fastapi uvicorn pycapcut openai google-genai fish-audio-sdk faster-whisper pillow`
- video-subtitle-remover (별도 설치, PyTorch 포함, 용량 큼)

### 하드웨어
- 자막 제거·Whisper는 NVIDIA GPU가 있으면 쾌적. Mac(Apple Silicon)도 가능하나 자막 제거는 느림.
- 디스크: 프로젝트당 원본+중간파일 수 GB.

| 5. 2번 쇼핑숏츠 | 장면 분석 + 매칭 + 검수 UI | 완성 2호 |
| 6. 3·4번 | 클립 카탈로그 + 컷 규칙 | 완성 3·4호 |

5번(장면 매칭 검수 UI)이 가장 공이 많이 들고, 2번(보조 도구)이 가장 빨리 체감된다.

## 9. 벤치마크에서 가져올 UI 요소 (캡처 기준)

- 5단계 스텝 표시: 원본 입력 → 대본 각색 → 레이아웃 세팅 → 세부 편집 → 완료
- 원본 업로드 화면: 최대 N개, 총 길이 한도 표시, 순서 변경(↑↓), 구간 편집, 9:16 크롭, 광고 표시 토글
- 구간 자르기 & 9:16 크롭 통합 편집: Fit Mode(꽉 채우기/전체 맞추기/커스텀), 줌 슬라이더, X/Y 오프셋, 타임라인 핸들 드래그, 현재 위치를 시작/종료로 설정
- 대본 설정: 타임라인 배치 정보, AI 대본 생성 / 수동 대본 입력 탭, 각색·제목 프롬프트 프리셋, 오프닝·아웃트로 멘트, TTS 성우 선택(전체/여성/남성), TTS 스타일 프리셋, "대본 장면 분할하기"
- 썸네일 제작: 영상에서 장면 캡처(±0.1s 이동) → 문구 입력 → 그림자·테두리·색상 → PNG 저장
- 설정: 채널 목록, API 키(TTS 엔진 등), 메뉴별 AI 프롬프트·레이아웃 프리셋
