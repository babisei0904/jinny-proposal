# 영상 자동화 프로그램 개발 검토서 (3차)

작성일: 2026-10-19

## 3차 변경 (숏튜브 쇼핑숏츠 흐름을 직접 구현)

- 1~4번을 따로 두지 않고 **'영상 만들기' 하나**로 합쳤다. 숏튜브 쇼핑숏츠의 5단계(원본 입력, 대본 각색, 레이아웃 세팅, 세부 편집, 완료)를 녹화와 스크린샷을 보고 그대로 만들었다.
- 숏튜브 사이트는 이 개발 환경에서 접속되지 않아(연결 실패) 코드를 볼 수 없었다. 접속되더라도 AI 분석·목소리 같은 서버 쪽 처리는 볼 수 없다.
- 유료 API 대신 무료 수단을 썼다.

| 숏튜브 기능 | 영상 작업실의 무료 대체 |
|---|---|
| 동영상 AI 분석 및 대본 추출 | Gemini 무료 키(영상 직접 분석) 또는 ChatGPT 복사·붙여넣기(장면 캡처 이미지) |
| Typecast 성우 TTS | Edge TTS(키 없음), Gemini TTS(무료 키, 말투 지시), Fish Audio 무료 모델, Mac 기본 음성 |
| 7~12자 자막 장면 분할 | 프로그램 안에서 자동 분할 |
| 레이아웃·렌더링 | 브라우저에서 레이어를 그리고 ffmpeg로 MP4 합성 (미리보기와 결과가 같은 그리기 코드 사용) |

- 테스트: 리눅스 크롬(헤드리스)에서 5단계 전체를 실행해 1080×1920 MP4가 만들어지는 것까지 확인했다. Edge 목소리, ChatGPT 방식, 수동 대본은 실제로 돌려 봤다. Gemini 분석, Gemini 목소리, Fish Audio는 키가 없어 실제 호출은 확인하지 못했다.
- 자막 제거는 여전히 숏튜브 바로가기로 둔다 (GPU AI 작업이라 Mac에서 느림).

## 2차 결정 사항

| 항목 | 결정 |
|---|---|
| 작업 PC | Mac |
| 1~4번 영상 제작 | **숏튜브 쇼핑숏츠 기능**으로 만든다. 네 종류 모두 "영상 올리기 → 대본 → 목소리 → 자막 → 완성" 같은 흐름이라서 |
| 이 프로그램이 맡는 일 | 대시보드, **사진 → 영상 만들기**, 클립 합치기, 프롬프트 보관함 |
| 유료 API | 쓰지 않는다. ChatGPT·Gemini·구글 플로우·Fish Audio·브루는 대시보드에서 사이트/앱을 여는 바로가기로 대체 |
| 자막 제거·자르기·썸네일·용량 줄이기 | 숏튜브 기능을 바로가기로 연결 |
| 캡컷/pycapcut | 이번 범위에서 제외 (숏튜브가 편집과 MP4 내보내기를 직접 함) |
| 3번 일상 영상 AI 장면 분석 | 지금은 ChatGPT용 장면 분석 프롬프트만 보관함에 저장. 자동 배치는 나중에 |

## 숏튜브 연결 검토

- **숏튜브는 캡컷을 쓰지 않는 것으로 보인다.** 사용 영상에서 숏튜브는 브라우저 안의 자체 편집 화면(구간 자르기, 9:16 크롭, 레이어, 자막, 썸네일)에서 작업하고 MP4·PNG를 바로 내려받았다. 캡컷 화면이 나온 것은 다른 사람의 유튜브 강의 영상(여행 숏핑숏츠)이었다. 숏튜브 내부 구조는 사이트가 이 환경에서 열리지 않아(503) 직접 확인하지 못했다.
- **공개 API는 찾지 못했다.** 숏튜브는 로그인·결제가 있는 웹 서비스라, 다른 프로그램이 파일을 대신 올리거나 결과를 받아오는 공식 방법이 없다. 브라우저 자동 클릭으로 흉내 내는 방법은 화면이 바뀌면 깨지고 이용약관 문제가 있을 수 있어 권하지 않는다.
- **그래서 연결은 바로가기 방식으로 했다.** 대시보드 버튼이 숏튜브의 해당 기능 화면을 새 탭으로 연다. 주소는 설정에서 바꿀 수 있다.
- **업로드 한도에 맞춘 합치기 기능을 넣었다.** 숏튜브 쇼핑숏츠는 영상 3개, 합계 180초까지 받는다(캡처 화면 기준). 사진 7장으로 클립 7개를 만들면 그대로 못 올리므로, 1~3개로 합치는 기능을 만들었다.

## 사진 → 영상 두 가지 방법

| | 방법 A. 구글 플로우 | 방법 B. 무료 바로 만들기 |
|---|---|---|
| 결과 | AI가 물·나뭇잎·커튼까지 움직이는 자연스러운 영상 | 사진을 천천히 확대·이동하는 효과 (사진 속 물체는 안 움직임) |
| 비용 | 플로우 무료 크레딧/구독 범위 | 무료 |
| 시간 | 장당 수십 초~수 분 + 수작업 | 장당 몇 초, 자동 |
| 프로그램이 해주는 일 | 사진마다 메모·움직임을 넣은 프롬프트를 만들어 복사, 플로우 열기 | 영상 생성, 1개 또는 숏튜브용 3개로 합치기 |

## 나중에 3번(일상 컷편집)을 자동화한다면

유료 API 없이도 가능한 길이 있다. 프로그램이 각 클립의 장면 캡처를 한 장짜리 이미지로 만들어 주면, 사용자가 ChatGPT에 올리고 저장된 "장면 분석" 프롬프트로 컷 목록을 받는다. 그 컷 목록을 프로그램에 붙여넣으면 클립을 잘라 순서대로 합친다. 필요하면 다음 단계로 진행한다.
