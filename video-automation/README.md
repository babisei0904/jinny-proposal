# 영상 작업실

쇼핑·여행·일상·브이로그 숏츠를 만드는 내 Mac용 프로그램입니다.
로그인이 없고 유료 API도 쓰지 않습니다. 영상 처리는 모두 내 컴퓨터 안에서 합니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| **영상 만들기** | 숏튜브 쇼핑숏츠와 같은 5단계: 원본 입력 → 대본 각색 → 레이아웃 세팅 → 세부 편집 → 완료 (MP4) |
| 썸네일 제작 | 숏튜브와 같은 4단계: 영상 선택 → 장면 캡처(9:16·16:9·1:1·원본) → 문구·배지·펜 꾸미기 → PNG 저장과 썸네일을 영상 맨 앞(또는 끝)에 넣은 MP4 |
| 사진 → 영상 | 사진마다 구글 플로우 프롬프트 자동 작성, 또는 무료 줌·이동 효과 영상 바로 만들기 |
| 클립 합치기 | 여러 영상을 1~3개로 이어 붙이기 |
| 프롬프트 보관함 | 자주 쓰는 프롬프트 저장. 대시보드에서 분류별 목록으로 골라 바로 복사 |
| 설정 | 무료 AI 키, 내 Fish Audio 목소리, 오프닝·아웃트로 멘트, 바로가기 주소 |

## 영상 만들기 5단계

1. **원본 입력**: 영상 최대 10개 업로드, 순서 정하기, 구간 자르기와 9:16 크롭(꽉 채우기, 전체 맞추기, 직접 커스텀, 확대, 위치), (광고) 표시
2. **대본 각색**
   - AI 대본생성: Gemini 무료 키가 있으면 영상의 화면과 말소리를 직접 분석해요. 키가 없으면 장면 캡처 이미지와 프롬프트를 ChatGPT에 붙여넣고 답을 다시 붙여넣어요.
   - 수동 대본 입력: 대본을 7~12자 자막 장면으로 자동 분할
   - 각색·제목 프롬프트 프리셋, 오프닝·아웃트로 멘트, 목소리와 스타일 선택, 장면마다 목소리 따로 지정
3. **레이아웃 세팅**: 자막·에셋 이미지·도형·테두리 레이어를 끌어서 배치, 글꼴·색·그림자·테두리 편집, 레이어 순서, 내 레이아웃 저장
4. **세부 편집**: 장면 타임라인, 실시간 미리보기(영상+목소리+자막), 장면별 자막·추가 자막·레이어 숨기기, 목소리 재합성
5. **완료**: 1080×1920 MP4 만들기, 다운로드, 제목·대본 복사, 제목·설명·해시태그용 ChatGPT 프롬프트

### 목소리

| 엔진 | 필요한 것 | 특징 |
|---|---|---|
| 타입캐스트 | 타입캐스트 API 키 | 숏튜브와 같은 AI 성우. 감정(기쁨·차분함·속삭임 등) 반영. 1글자 = 1크레딧, 무료 플랜은 매달 한도 있음 |
| Edge (기본) | 없음 | 마이크로소프트 엣지의 읽기 음성. 한국어 3명 (선희, 인준, 현수). 인터넷 필요 |
| Gemini | Gemini 무료 키 | 말투 지시(예: 다큐 내레이터)가 반영됨. 하루 무료 사용량이 적음 |
| Fish Audio | Fish Audio API 키 | 무료 모델 s2.1-pro-free로 내 목소리 모델 사용 |
| Mac 기본 | 없음 | 인터넷 없이 동작 (유나) |

## 처음 한 번만 (터미널)

```bash
# 1) ffmpeg 설치 (이미 있으면 건너뛰기)
brew install ffmpeg

# 2) 코드 받기
cd ~/Desktop
git clone -b claude/video-automation-program-review-5ali00 https://github.com/babisei0904/jinny-proposal.git 영상작업실-repo
cd 영상작업실-repo/video-automation

# 3) 파이썬 환경 만들기
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

이미 받은 적이 있으면 `git pull` 후 `pip install -r requirements.txt` 를 한 번 더 실행하세요.

## API 키 넣기 (선택)

키는 본인 계정에서 발급받아 **설정 → 무료 AI 연결**에 붙여넣고 [설정 저장]을 눌러요. 키는 이 컴퓨터의 data 폴더에만 저장돼요.

**Gemini (영상 자동 분석, Gemini 목소리)**
1. https://aistudio.google.com/apikey 에 구글 계정으로 로그인해요.
2. **Create API key**를 눌러 나온 키(AIza로 시작)를 복사해요.
3. 무료 등급은 하루 사용량이 정해져 있고, 입력 내용이 구글 서비스 개선에 쓰일 수 있어요. 키가 없어도 ChatGPT 방식으로 모든 단계를 할 수 있어요.

**타입캐스트 (AI 성우)**
1. https://typecast.ai/developers/api/ 에서 로그인한 뒤 API 콘솔로 들어가요.
2. API 키를 만들어 복사해요.
3. 설정에 붙여넣고 [타입캐스트 목소리 목록 새로고침]을 누르면 2단계 목소리 목록에 타입캐스트 성우가 나와요.
4. 1글자가 1크레딧이에요. 무료 플랜은 매달 정해진 크레딧만 쓸 수 있고, 무료 플랜 음성은 상업적 이용 불가·출처 표기 필요로 안내돼 있어요. 쇼핑숏츠처럼 수익이 나는 영상에는 유료 플랜 조건을 확인하세요.
5. 2단계의 [▶ 미리듣기]는 타입캐스트가 제공하는 샘플을 재생해서 크레딧을 쓰지 않아요.
