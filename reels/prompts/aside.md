# Aside 지시문 템플릿

`/stay-reel` 스킬이 Aside(MCP `exec` 도구 또는 `aside "..."` 명령)에 보내는 지시문.
`{중괄호}` 는 스킬이 채운다. 경로는 항상 `/Users/...` 로 시작하는 전체 경로를 쓴다 (`~` 를 못 알아듣는 경우가 있었다).

## A. 사진 수집 (3단계)

```
{숙소이름}({지역}) 숙소 사진을 모아줘.
찾는 순서: 1) 공식 홈페이지 {공식URL 또는 "검색해서 찾기"}  2) 여기어때, 야놀자, 아고다, 트립닷컴의 이 숙소 페이지  3) 네이버 블로그 후기.
조건:
- 숙소를 잘 보여주는 사진 {장수}장. 아래 장면이 골고루 들어가게: {필요한 장면 목록}
- 세로로 잘라도 주인공이 살아 있는 사진, 가로 1000px 이상, 글자·로고·워터마크가 크게 박힌 사진은 제외
- 같은 장면은 가장 잘 나온 1장만
- {폴더}/photos/ 에 01.jpg, 02.jpg ... 순서로 저장
- 사진마다 {폴더}/sources.csv 에 한 줄씩: 파일명,출처사이트,페이지주소,이미지주소,장면설명
로그인이나 결제가 필요한 화면이 나오면 멈추고 알려줘. 한 사이트에서 너무 빠르게 많이 열지 마.
```

## B. Flow 영상화 (6단계, 사진 1장마다)

```
labs.google/fx/tools/flow 에서 프로젝트 "{숙소이름}" 을 열어 (없으면 새로 만들어).
'프레임으로 동영상 만들기(Frames to Video)' 모드, 모델 {model}, 비율 {aspect}, 해상도 {resolution}, 길이 {duration}, 개수 1 로 설정해.
{폴더}/photos/{파일} 을 첫 프레임으로 업로드하고, 프롬프트 입력칸에 아래 영어 문장을 한 글자도 바꾸지 말고 붙여넣어:
'{프롬프트}'
생성 버튼을 누르기 직전 화면을 {폴더}/clips/{이름}_before.png 로 캡처하고,
완성되면 {해상도} 원본으로 다운로드해서 {폴더}/clips/{이름}.mp4 로 저장해줘.
```

계절 편집이 필요한 사진은 먼저 이렇게 한다:

```
labs.google/fx/tools/flow 에서 {폴더}/photos/{파일} 을 업로드해 이미지 편집으로 아래 문장을 적용하고,
결과 이미지를 {폴더}/photos/{이름}_{계절}.jpg 로 저장해줘: '{season_edits 문장}'
```

## C. 업로드 (10단계, 채널 1곳마다)

```
{채널} 에 로그인된 계정으로 영상을 올려줘.
- 영상 파일: {폴더}/out/reel.mp4
- 표지/썸네일: 영상 첫 프레임 (설정이 있으면 0초 프레임 선택)
- {채널별 입력칸}: {폴더}/captions.md 의 '{채널}' 부분을 그대로 붙여넣기
- 공개 범위: {공개 | 비공개 | 임시저장}
- 광고 표시: {협찬이면 '유료 광고 포함/브랜디드 콘텐츠' 표시를 켜기}
- AI 생성 콘텐츠 표시 항목이 있으면 켜기
'게시' 버튼을 누르기 직전에 화면을 {폴더}/upload/{채널}_before.png 로 캡처하고, 멈춰서 확인을 받아.
게시 후에는 게시물 주소를 알려줘.
```
